إضافة رصد لمتصفح Edge / Chrome
================================
1) شغّل الخادم أولاً:  python app.py   (من مجلد server)
2) في المتصفح افتح:  edge://extensions   (أو chrome://extensions)
3) فعّل «وضع المطور» (Developer mode).
4) اضغط «Load unpacked» (تحميل غير مُعبّأ) واختر مجلد extension هذا.
5) افتح أي موقع واضغط أيقونة رصد: تظهر نتيجة فحص الصفحة الحالية.

ملاحظات
- لا يُرسَل أي شيء إلا عند فتح نافذة الإضافة، ويُرسَل رابط الصفحة الحالية فقط إلى خادمك.
- عند نشر الخادم على الإنترنت: ضع عنوانه في خانة «عنوان الخادم» داخل الإضافة،
  وأضفه أيضاً إلى host_permissions في ملف manifest.json ثم أعد تحميل الإضافة.
